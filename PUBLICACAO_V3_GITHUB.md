# Publicação V3 — GitHub Pages

Esta versão foi preparada para substituir/atualizar a publicação existente **sem apagar a arquitetura anterior**.

## Estrutura esperada na raiz do repositório
- `index.html`
- `assets/`
- `servicos/`
- `conteudo/`
- demais páginas e arquivos já presentes no pacote.

## Atenção
O site V3 usa **`assets/`**. Não renomear a pasta para `ativos`.

## Forma mais simples
1. Extraia o ZIP completo no computador.
2. Abra o repositório GitHub `Ordoneagroambiental/midia` na raiz.
3. Use **Add file → Upload files**.
4. Envie os arquivos e pastas da raiz do pacote extraído, preservando a estrutura.
5. Confirme as alterações na branch principal.
6. Aguarde o GitHub Pages concluir a implantação.
7. Atualize a página com recarregamento completo.
