# PUBLICAR A ORDONE SEM CUSTO INICIAL

## Opção recomendada: GitHub Pages

1. Criar uma conta no GitHub.
2. Criar um repositório público para o site.
3. Enviar todos os arquivos desta pasta para a raiz do repositório.
4. Abrir `Settings` → `Pages`.
5. Selecionar `Deploy from a branch`.
6. Selecionar `main` e `/ (root)`.
7. Salvar.
8. O GitHub fornecerá o endereço gratuito.

### Teste 4 — CRM gratuito
1. Criar Google Sheets.
2. Abrir Apps Script.
3. Usar `backend_google_apps_script/Code.gs`.
4. Publicar como aplicativo da Web.
5. Colocar a URL `/exec` em `assets/lead-config.js`.
