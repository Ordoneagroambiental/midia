# ORDONE AGROAMBIENTAL — PUBLICAÇÃO GRATUITA V13

## OBJETIVO
Colocar o site no ar sem comprar domínio e sem contratar hospedagem.

## ETAPA 1 — GitHub Pages
1. Criar uma conta no GitHub, caso ainda não tenha.
2. Criar um repositório público.
3. Descompactar o ZIP da V13.
4. Enviar o conteúdo da pasta do site para a raiz do repositório.
5. Abrir Settings → Pages.
6. Em Source, selecionar Deploy from a branch.
7. Selecionar `main` e `/ (root)`.
8. Salvar.
9. O GitHub fornecerá o endereço gratuito do site.

## ETAPA 2 — TESTE
Testar no computador:
- Home
- Problemas
- Serviços
- Diagnóstico
- Biblioteca
- Projetos
- WhatsApp

Testar no celular:
- menu
- botão WhatsApp
- formulário
- links
- leitura dos textos

## ETAPA 3 — LEADS
Quando a versão publicada estiver funcionando:
1. Criar Google Sheet.
2. Abrir Extensões → Apps Script.
3. Usar `backend_google_apps_script/Code.gs`.
4. Publicar como aplicativo da Web.
5. Colar a URL `/exec` em `assets/lead-config.js`.

## ETAPA 4 — PRIMEIRO TESTE REAL
Fazer um cadastro fictício:
- nome;
- WhatsApp;
- município;
- demanda;
- descrição.

Confirmar:
1. ficha;
2. WhatsApp;
3. linha no Google Sheets;
4. e-mail de aviso, se configurado.

## IMPORTANTE
Não comprar domínio nesta fase.
Não contratar CRM.
Não contratar hospedagem.
Não armazenar automaticamente documentos dos clientes antes de definir a política de dados.

A primeira meta é provar que o fluxo:
VISITANTE → DIAGNÓSTICO → LEAD → WHATSAPP
funciona.
