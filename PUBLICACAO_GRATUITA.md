# PUBLICAÇÃO GRATUITA — ORDONE AGROAMBIENTAL V5

A V5 está preparada para hospedagem estática gratuita.

## Publicação
GitHub Pages:
1. Criar conta gratuita.
2. Criar repositório público.
3. Enviar todos os arquivos.
4. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
5. Publicar.

## Estratégia comercial da V5
O site agora possui páginas orientadas à intenção de busca:
- recebi-notificacao.html
- preciso-prad.html
- preciso-mapa.html
- preciso-analisar-solo.html
- problemas.html

Cada página leva o visitante para diagnóstico ou WhatsApp.
