## Colocar no ar sem custo
1. Criar repositório público no GitHub.
2. Enviar os arquivos.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Usar o endereço gratuito fornecido pelo GitHub Pages.

## Captar leads
1. Criar Google Sheet.
2. Abrir Extensões → Apps Script.
3. Colar `backend_google_apps_script/Code.gs`.
4. Publicar como Aplicativo da Web.
5. Copiar a URL `/exec`.
6. Colar em `assets/lead-config.js`.
